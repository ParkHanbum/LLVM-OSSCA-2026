PR #229086 · 공개 데이터 범위

N=60의 A/A wall, A/B wall, 프로파일 A/A, 진단용 Add A/B는 각각 60쌍을 유지합니다.
처음 12쌍 실험 4개는 별도로 보관합니다. N=60과 합산하지 않습니다.
summary.json에는 총 8개 실행의 표본 576개, 구간별 집계, 검증·입력·커널 해시와 Add 노드 형상이 있습니다.
프로파일 표본은 같은 측정 표본에 Add/model_run 집계를 연결한 것이므로 추가 관측으로 세지 않습니다.
진단용 Add A/B는 앞선 프로파일 A/A의 CV 5.411%가 기준 5%를 넘긴 후 수집됐습니다. 인과적 개선 근거로 사용하지 않습니다.
프로파일의 user/system CPU는 전체 교차 실행 쌍의 공유 시간입니다. A/B 개별 CPU 시간으로 나누지 않습니다.
모델 가중치, 입력 이미지, 실행 바이너리, 인터프리터, 전체 ORT 노드 trace·개별 추론 trace는 배포하지 않습니다.
서버 절대 경로와 실행 중 커널 주소는 공개 JSON에서 제외했습니다. 측정 수치는 변경하지 않았습니다.
이 페이지를 만들며 추론·벤치마크를 다시 실행하지 않았습니다.
