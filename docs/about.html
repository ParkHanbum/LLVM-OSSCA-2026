ASD-STE100 원칙의 한국어 적용

ASD-STE100은 영문 기술 문서의 작성 규칙과 통제 어휘를 제공하는 표준입니다. 이 문서집은 한국어를 유지하며 안내·해설·결과 페이지에 명료한 문장과 일관된 용어의 원칙을 적용했습니다.

  • 한 문장에는 한 가지 핵심 내용을 적습니다.
  • 한 문단에는 하나의 주제를 설명합니다.
  • 주어와 적용 조건을 분명히 적습니다.
  • 절차는 한 단계씩 번호로 나눕니다.
  • 같은 개념에는 같은 용어를 씁니다.
  • 코드, 명령어와 식별자는 원래 표기를 유지합니다.

원문 전문은 작성자의 설명과 표현을 보존합니다. 글을 짧게 만들기 위해 내용을 삭제하지 않습니다. 한국어 문서의 영문 통제 사전 적합성이나 공식 인증을 주장하지 않습니다.

성과와 검증의 표기

기존 패치 분석, 기여 과정, 실험·제안을 구분합니다. 연결된 PR이 모두 자료 작성자의 신규 PR이라는 뜻은 아닙니다.

구현, 테스트, 병합 상태와 측정 수치는 각 원자료의 기록입니다. 문서 변환 중 LLVM 빌드·벤치마크를 새로 실행하거나 모든 PR의 현재 상태를 다시 조회한 결과는 아닙니다.

Alive2의 의미 검증, IR 변화, 기계어 변화, llvm-mca의 정적 추정과 실제 실행 시간은 별도로 표시합니다. 성공한 작은 예제의 수치를 전체 응용 프로그램의 개선율로 바꾸지 않습니다.

문서 전문과 페이지 배치

문서를 열면 요약 대신 전문을 바로 읽을 수 있습니다. 각 버전의 내용·구현 상태·수치를 합치거나 최신 상태로 바꾸지 않았습니다. 기존의 짧은 해설은 전문 뒤의 핵심 원리와 편집 주석에서 별도로 제공합니다.

PDF의 본문은 읽기 순서·코드 블록·표를 나누고 그림을 함께 제공합니다. 스크린샷과 이미지 속 글자는 로컬 문자 인식으로 옮겼습니다. PDF 336쪽과 PPTX 67장의 원래 페이지 이미지도 모두 포함합니다. 본문과 그림 보기, 원래 페이지 배치 보기를 바꿀 수 있습니다.

이미지 문자 인식과 일부 PDF 글꼴의 코드 기호는 정확하지 않을 수 있습니다. 이 경우 페이지 배치나 그림을 함께 확인할 수 있습니다. DOCX·Markdown·HTML의 원문 단락·표·코드·그림도 전문으로 수록했습니다.

원자료에서 번호나 식의 경계, 집계가 달라지는 부분은 편집 주석으로 밝혔습니다. 미첨부 작업 파일 링크에는 미첨부 표시를 붙였습니다. 제출되지 않은 측정 로그와 스크립트는 새로 만들어 채우지 않았습니다.

출처와 저작물 표기

각 문서의 출처는 해당 멘티의 제출 자료입니다. 코드 발췌와 공개 리뷰는 연결된 LLVM 프로젝트의 원문을 함께 확인할 수 있습니다.

원자료의 권리는 각 작성자와 해당 저작권자에게 있습니다. LLVM 코드에는 프로젝트의 Apache-2.0 WITH LLVM-exception 라이선스를 확인하세요.
