기술 이름과 코드 식별자는 원래 표기를 유지합니다. 아래 설명은 이 문서집을 읽는 데 필요한 범위의 뜻입니다.

LLVM IR
LLVM의 중간 표현이다. 프론트엔드가 만든 프로그램을 공통 최적화와 백엔드가 처리할 수 있는 명령어로 나타낸다.
InstCombine
작은 IR 패턴을 더 단순하거나 정해진 형태로 바꾸는 패스다. 최종 기계어를 직접 선택하는 단계와 구분한다.
InstSimplify
새 명령어를 만들지 않고 기존 값이나 상수로 바꿀 수 있는지 판단하는 단순화 계층이다.
ValueTracking
IR 값의 범위, 비트, 값 사이의 관계 등을 분석하는 공용 기능이다. 여러 최적화가 이 정보를 사용한다.
fold
조건을 만족하는 식을 더 단순한 표현으로 바꾸는 규칙이다. 이 문서에서는 단순화 또는 정규화 규칙을 뜻한다.
canonicalization
같은 의미를 표현하는 여러 모양을 후속 최적화가 다루기 쉬운 정해진 형태로 정리하는 것이다.
PatternMatch
LLVM IR의 구조와 조건을 선언적으로 검사하는 도구다. m_Value, m_OneUse 같은 matcher를 조합한다.
SSA value
한 번 정의한 값을 가리킨다. matcher에서 같은 값이라는 조건은 보통 비슷한 이름이 아니라 같은 IR 값을 뜻한다.
one-use / multi-use
현재 값의 사용 횟수가 하나인지 여러 개인지 구분한다. 새 식으로 바꾼 뒤 기존 계산이 사라지는지에 영향을 준다.
select
조건에 따라 두 값 중 하나를 선택한다. 선택하지 않은 값의 poison은 결과로 전달하지 않는다.
PHI
제어 흐름이 합쳐지는 지점에서 실제로 들어온 경로에 대응하는 값을 선택한다.
poison
명령어의 의미 조건을 위반한 경우에 생길 수 있는 값이다. 즉시 프로그램 전체가 실패한다는 뜻과 구분한다.
undef
사용 시점에 선택할 수 있는 정의되지 않은 값을 나타낸다. 같은 SSA 이름의 일반 입력값과 같은 안정성을 가정하지 않는다.
freeze
poison 또는 undef를 임의의 고정된 정상 값으로 만든다. 선택 경로가 가리던 poison을 새 식이 노출할 때 필요할 수 있다.
refinement
원본이 허용하는 동작을 보존하면서 더 구체적인 결과로 바꾸는 관계다. 원본의 정의된 결과를 poison으로 바꾸는 것은 허용되지 않는다.
demanded bits
현재 결과를 계산하는 데 실제로 필요한 비트다. 쓰지 않는 비트의 차이는 해당 사용처의 결과에 영향을 주지 않을 수 있다.
DemandedElts
vector에서 필요한 원소를 나타내는 마스크다. 마스크의 폭은 분석 대상 타입의 원소 수와 맞아야 한다.
fast-math flags
부동소수점 최적화에 추가 가정을 허용하는 플래그다. 모든 플래그를 같은 가정으로 취급하지 않는다.
nsz
부동소수점 최적화에서 +0과 -0의 차이를 무시할 수 있게 하는 플래그다.
nnan / ninf
각각 NaN과 무한대가 없다는 관련 가정을 허용한다. 어떤 명령어에 붙었는지와 위반 시 의미를 함께 확인한다.
nuw / nsw
정수 연산에서 각각 unsigned·signed wrap을 허용하지 않는 조건이다. trunc에 붙으면 입력의 가능한 범위를 제한할 수 있다.
nneg
zext 입력이 음수가 아님을 나타내는 조건이다. 전제를 만족하면 같은 입력의 sext와 결과가 같을 수 있다.
intrinsic
LLVM이 의미를 알고 처리하는 내장 연산 호출이다. 이름이 비슷한 일반 라이브러리 함수와 처리 경로가 다를 수 있다.
libcall
일반 라이브러리 함수 호출이다. IR의 단순한 연산이 특정 타깃에서 함수 호출로 내려가면 비용이 늘 수 있다.
Alive2
LLVM IR 변환의 정확성을 형식적으로 확인하는 도구다. 성공, 반례, 시간 초과와 지원 범위를 구분한다.
opt / llc
opt는 IR 최적화 패스를 실행하는 도구다. llc는 IR에서 타깃 기계어를 만드는 백엔드 도구다.
lit / FileCheck
lit은 테스트를 실행한다. FileCheck는 출력에 기대하는 패턴이 나타나는지 검사한다.
llvm-mca
CPU scheduling model로 코드 블록의 실행 비용을 추정하는 도구다. 실제 응용 프로그램의 실행 시간 측정과 구분한다.
Block RThroughput
같은 블록을 반복할 때 모델이 추정한 처리 간격이다. 다른 조건이 같을 때 작은 값이 더 높은 처리량을 나타낸다.
NFC
No Functional Change의 약자다. 기능이나 출력 동작을 바꾸지 않는 변경이라는 뜻이다.
denormal / FTZ
denormal은 0에 매우 가까운 비정규 부동소수점 값이다. FTZ는 일부 작은 결과를 0으로 처리하는 모드다.
saturation / wraparound
포화는 범위 밖 결과를 최솟값·최댓값으로 제한한다. wraparound는 정해진 비트 폭의 나머지 값으로 돌아간다.
scale / zero point
양자화에서 정수 값과 원래 값 사이의 변환에 쓰는 배율과 기준점이다. 서로 다른 입력은 보정 없이 바로 더할 수 없다.
