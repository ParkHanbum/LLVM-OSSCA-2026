1. 가장 간단한 게시 방법

  1. 압축을 풀고 llvm-mentee-docs 폴더를 엽니다.
  2. GitHub 저장소의 루트에 docs 폴더를 올립니다. 다른 파일도 함께 보관할 수 있습니다.
  3. 저장소의 Settings → Pages를 엽니다.
  4. Build and deployment → Source에서 Deploy from a branch를 선택합니다.
  5. 업로드한 브랜치를 선택하고 폴더를 /docs로 지정합니다.
  6. Save를 누릅니다. 배포가 끝나면 같은 화면에 사이트 주소가 표시됩니다.

저장소 안에 상위 폴더를 하나 더 만들지 말고, 저장소 루트에 docs/index.html이 위치하도록 올리세요. 페이지 간 링크와 그림 경로는 GitHub Pages의 저장소 하위 주소에서도 동작하도록 작성했습니다.

선택 사항: GitHub Actions로 배포하기
  1. deployment/pages.yml을 저장소의 .github/workflows/pages.yml로 복사합니다.
  2. Settings → Pages → Source를 GitHub Actions로 설정합니다.
  3. Actions → Publish documentation to GitHub Pages → Run workflow로 최초 배포를 실행합니다.
  4. 이후 기본 브랜치의 docs 변경은 같은 workflow로 배포합니다.

이 설정을 사용할 때는 위의 브랜치 게시 방식 대신 GitHub Actions를 게시 소스로 선택합니다. GitHub 공식 workflow 안내
